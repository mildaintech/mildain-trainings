# **App Name**: EstateGraph

## Core Features:

- Property Grid: Display listings in a grid layout as shown in the Figma design.
- Dashboard Replication: Implement a detailed property dashboard replicating the Figma design, including charts and data displays.
- Image Gallery: Show image galleries in the same style as your Figma design, and support swiping between photos.
- Fullscreen View: Allow the option to view each property in a fullscreen view. 
- Property Import: Make calls to a service to populate the site with real estate listings.

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF) to suggest ease and creativity. This color evokes calmness and sophistication, aligning with the goal of a comfortable and user-friendly experience.
- Background color: Light grey (#F0F0F0), complementing the soft lavender hue and enhancing readability while maintaining a gentle aesthetic.
- Accent color: Pale violet-red (#D87093), adds contrast to call to action items while enhancing sophistication. 
- Font pairing: 'Belleza' (sans-serif) for headlines and short chunks of text; 'Alegreya' (serif) for body text. Note: currently only Google Fonts are supported.
- Adopt a grid-based layout system that is identical to your Figma file. This consistent design, and modular design creates an intuitive user experience that enhances information discoverability. 
- Use a modern and simplified icon set to represent common actions. All icon styles match with the existing design system for enhanced cohesion.
- Use a smooth transition effect on image slideshow for increased aesthetics. No additional distracting or overwhelming transitions.
